#+TITLE: Kolabi Org Strategy Table CLI Examples

This file shows the active strategy grammar used by =kolabi.bot=. Strategy files are Org tables, and =run-once= uses the same typed value syntax for one pair.

* Typed Value Rules

- =qty= is required and starts with =A=, =%=, or =U=, for example =A11= or =U15= for USD notional converted from mark price.
- =pGate= is a typed two-bound interval, for example =D1 2=, =D- +=, =B-100.50 99.50=, or =A79320 79340=.
- =hPrice= is a lazy typed head price, for example =D6=, =B19.98=, or =A79350=; it is computed only when =pGate= opens.
- =tPrice= is a typed tail distance, for example =D20=, =B119.29=, or =A0.25=.
- =hDelta= starts with =D= or =B= when present and is only for =SL= or =LT= head trigger-to-limit offsets.
- =tDelta= starts with =D= when present.
- =tUblk= starts with =D= or =B= when present.
- =wUblk= is a plain number of minutes; blank defaults to 6.
- Optional =rFunc= names a pure Python repeat adjustment registered by the ignored =orders/rfunc.py= strategy file, or by the file named in =KOLABI_STRATEGY_RFUNC=. Use =name: x,y= to pass numeric arguments.

Removed compatibility flags and old keyword spellings are intentionally absent: =--aType=, =-a=, =--quantity=, =-q=, =--tailPrice=, =-T=, =--pgate=, =--hprice=, =--tp=, and =--oDelta= are no longer accepted.

* One Pair Commands

#+begin_src bash
python -m kolabi.bot run-once \
  --symbol PI_XBTUSD \
  --environment demo \
  --name XSellTail \
  --tps_run 0 1440 \
  --tOut 60 \
  --side sell \
  --oType L \
  --hPrice D1 \
  --qty A1 \
  --tType S- \
  --pGate 'D1 2' \
  --tPrice B49.88 \
  --dry-run

python -m kolabi.bot run-once \
  --symbol PI_XBTUSD \
  --environment demo \
  --name XLog \
  --tps_run 0 60 \
  --side buy \
  --oType L \
  --hPrice B49.88 \
  --qty A1 \
  --tType S- \
  --pGate 'B-100.50 99.50' \
  --tPrice B49.88 \
  --dry-run

python -m kolabi.bot run-once \
  --symbol PI_XBTUSD \
  --environment demo \
  --name XAbs \
  --tps_run 0 60 \
  --side sell \
  --oType L \
  --hPrice A79350 \
  --qty A1 \
  --tType S- \
  --pGate 'A79320 79340' \
  --tPrice D0.5 \
  --dry-run
#+end_src
